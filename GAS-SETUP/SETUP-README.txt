# お気に入りボックス v1.1.8 ― 初期設定手順

## ① 先にGitHubを更新
ZIPを解凍。GitHubに `index.html`、`manifest.webmanifest`、`sw.js`、`icons` を上書きして、GitHub Pagesの更新を確認。
`GAS-SETUP` はGitHubへアップロードしない。

## ② GASの合言葉を設定（例は使わず、自分で決める）
1. Googleスプレッドシートを開く → 上部「拡張機能」→「Apps Script」。
2. `GAS-SETUP/GoogleAppsScript.gs` をすべてコピーし、既存コードと置き換えて保存。
3. Apps Script左側の歯車「プロジェクトの設定」を開く。
4. 画面下の「スクリプト プロパティ」→「スクリプト プロパティを追加」。
5. **プロパティ**：`FAVBOX_ACCESS_CODE`
6. **値**：自分で決めた **半角英数字6～32文字**（例示の値は使わない）。
7. 「スクリプト プロパティを保存」。
8. Apps Scriptのエディタに戻り、関数のプルダウンから `setupSheet` を選んで「実行」→アクセス承認。

## ③ ウェブアプリを再デプロイ
初回：右上「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」。
既存：右上「デプロイ」→「デプロイを管理」→鉛筆（編集）→ バージョン「新しいバージョン」→「デプロイ」。
**実行するユーザー：自分**、**アクセスできるユーザー：全員**（匿名を含む）。
最後に発行される `/exec` で終わるURLをコピー。

## ④ お気に入りボックスで1度だけ入力
1. 公開したお気に入りボックスを開く。
2. 下側の「Googleスプレッドシート連携」を開く。
3. 「GASのウェブアプリURL」に `/exec` のURLを貼る。
4. 「GAS連携の合言葉」に②と同じ半角英数字を入れる。
5. 「連携設定を保存」→「接続テスト」。
6. 「✓ 接続確認OK」が出たら設定完了。登録済みURLは「既存のURLを一括転記」を押す。
7. 以前の送信が残っている場合は「未確認分を再送」を押す。

## 表示が更新されないとき
最新の `sw.js` もアップロード済みか確認し、オンラインでアプリを再読み込みしてください。

## 安全上の注意
6文字は最低限の簡易保護です。サイトへのログイン認証ではありません。GASのURLや合言葉をGitHub等に公開しないでください。重要な個人情報を扱う用途には適しません。
