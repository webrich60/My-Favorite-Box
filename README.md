# お気に入りボックス v1.1.6 — 共有から最短保存（アプリ＋GAS同梱）

## 追加機能
- **Android Chrome**: GitHub Pagesのアプリを「インストール」すると、YouTubeやChromeの「共有」→「お気に入りボックス」で、共有したURLが**自動で1件登録**されます（対応するAndroid端末でインストールできた場合）。Androidで共有URLは `text` に入ることが多いため、両方に対応。
- 共有元のタイトルが届けば自動採用。届かない場合、既存のGAS連携を使いタイトルをバックグラウンド取得（取得できないサイトはサービス名などの仮タイトル）。
- 受信後も重複URLは登録せず、その旨を表示します。カテゴリはタイトル／URLのキーワードで自動判定、手動調整可能です。
- 共有先機能を使えない端末では「コピーしたURLをすぐ保存」ボタンを利用できます（クリップボードアクセスが許可された場合のみ）。
- 追加したマニフェスト／サービスワーカー／アイコンでインストール対応。猫アバター・視認性改善・GAS同期・独自カテゴリの機能は継続。

## 重要な制約
- **Safari / iOSの標準共有メニューにPWAを受け取り先として直接表示する機能は未対応**です。iPhoneではURLをコピーし、アプリの「コピーしたURLをすぐ保存」を使うか、URL欄に貼り付けて登録してください。
- **YouTube / Instagram / X のすべてのタイトルが取得できるわけではありません。** 共有アプリから受け取るタイトルが最優先、GASによる公開情報取得は補助です。GAS未設定では自動Webページタイトル取得を行えません。
- タイトル取得は公開されているHTTPSページに限定されます。ログインが必要な投稿・非公開ページなどは取得できない場合があります。
- GASでタイトル取得を使う場合は**同梱のv1.1.6用 `GoogleAppsScript.gs` に貼り直して「新しいバージョン」で再デプロイ**してください。旧版のままでも保存・転記は動きますがタイトル取得はできません。
- スプレッドシートへの自動転記には、アプリのGAS連携設定が必要です。端末別のブラウザ保存は従来どおりで、**スプレッドシートは他端末への同期元ではありません。**

## GitHub Pages導入（新規 / 更新）
GitHubのリポジトリの**ルート（index.htmlと同じ階層）**へ、下記をZIPからアップロードしてください。
```
index.html
manifest.webmanifest
sw.js
icons/icon-192.png
icons/icon-512.png
README.md  （任意）
```
`GAS-SETUP/` は**GitHubに絶対に公開しない**でください（合言葉の入ったGASを含む）。
`manifest.webmanifest` のaction等は相対URLなので、`https://ユーザー.github.io/リポジトリ名/` のGitHub Pagesで動作します。

### Androidで「共有」先へ追加する
1. スマホの **Chrome** でGitHub PagesのURLを開きます。
2. Chromeメニュー「アプリをインストール」または画面の「アプリをインストール」を実行します。*ホーム画面に置いただけのショートカットでは共有先にならないことがあります。*
3. YouTubeなどで好きな動画を開き「共有」をタップします。
4. 共有先の一覧から **お気に入りボックス** を選びます。自動で登録され、登録済みの場合は重複を防止します。
5. 共有先が現れない場合、Chromeアプリの更新・インストール状態を確認し、一旦アンインストール／再インストールを試します。機種や共有元によっては使えません。

### iPhone / 非対応端末
1. 動画・サイトの「共有」→「リンクをコピー」。
2. お気に入りボックスを開く→「コピーしたURLをすぐ保存」をタップ。権限要求が出たら許可。動かなければURL欄に貼り付けて「追加」。

## GAS設定
- `GAS-SETUP/GoogleAppsScript.gs` と `GAS-SETUP/SETUP-README.txt` を参照してください。
- 旧GASから更新する場合は `ACCESS_KEY` を**既存と同じ合言葉**に保ち、Apps Scriptでコードを全置換して「デプロイを管理 → 編集 → バージョンを新しいバージョン」で再デプロイします。
- GASに実在するスプレッドシートは個人用を想定し、アクセスURLと合言葉を第三者へ公開しないでください。
- GASは公開ページのタイトルを取得するため、登録先サイトへのリクエストが発生します。非公開URL／プライベート情報が含まれるリンクではご注意ください。

## データについて
ブラウザに `favbox.items.v1` と `favbox.custom.categories.v1` を使用する従来の保存方式を維持。サイトURL（オリジン）を変更すると別の保存領域になり、旧データは引き継がれません。事前にバックアップしてください。
