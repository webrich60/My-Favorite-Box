# お気に入りボックス v1.2.1（2026-11-11）

## この更新で直した点
- ヘッダーとフッターに **v1.2.1** を常時表示。以前の更新で `meta app-version` が古いままだった問題も修正。
- GAS連携の各操作ボタンは **常に1列・横書き**。画面幅が小さくても文字が縦に並びません。
- 「連携設定を保存」の保存方式は IndexedDB → localStorage → CacheStorage の順に試行し、**読み戻しを検証**。利用できた保存先を表示します。
- すべての保存先が使えないときは、利用できない保存先の種類を画面に表示します。保存成功と偽りません。
- 通信経由で古い画面が残らないよう、サービスワーカーのシェルキャッシュを更新。画面内に「最新の画面を読み直す」ボタンを追加。
- URL登録、カテゴリ、自動タイトル取得、猫アバター、共有から保存、GAS連携、既存の保存キーは維持。

## アップデート
1. 可能なら「バックアップ」から登録済みURLを控えておく。
2. `index.html` と `sw.js` を **GitHubリポジトリ直下**へ上書き（実際の公開ディレクトリが `docs/` ならその中へ）。
3. 初回公開なら `manifest.webmanifest` と `icons/` も同じ階層へ配置。
4. GitHub Pagesで使用している **公開URL**をChromeの通常タブで開き、上部に **v1.2.1** が表示されていることを確認。
5. 表示が古ければ公開URLの末尾に `?app_version=1.2.1` を付けて開く。**サイトデータやChromeの履歴を消さない**。
6. GASのURL・合言葉の設定画面で「連携設定を保存」→「接続テスト」。

今回 **GASコードに変更はありません**（v1.1.8以降と同一）。すでに正しくデプロイしているなら、貼り直しも再デプロイも不要です。

## セキュリティ
GASのスクリプトプロパティの合言葉はGitHubへアップロードしません。スクリーンショット等で公開してしまった合言葉は、念のため新しい値へ変更してください。
