# お気に入りボックス v1.1.8（GAS連携に合言葉を追加）

## 今回の変更
- **GAS連携専用の合言葉**を復活しました。半角英数字6～32文字、英字は大文字と小文字を区別します。
- GitHub Pagesのサイト表示にはログイン・合言葉は不要です。
- 合言葉はGoogle Apps Scriptの「スクリプト プロパティ」で管理し、GitHubの公開ファイルには記載しません。
- アプリ側では一度保存すれば同じブラウザで毎回の入力は不要です（ブラウザのローカルストレージへ保存）。
- GASの新規登録・更新・削除・接続テスト・タイトル取得・操作確認に合言葉の照合を追加。
- 登録済みのお気に入りデータ、カテゴリ、未送信キューは維持。
- 猫のアバター、読みやすい濃い文字・枠、Android共有、URL重複防止も維持。

## GitHubへのアップロード
- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icons/` フォルダ内のPNG画像2枚

**GAS-SETUPフォルダはGitHubへアップロードしないでください。**

## 注意点
- 6文字の合言葉は簡易保護です。推測・総当たり攻撃への強い耐性はありません。可能なら12文字以上のランダムな英数字を推奨します。
- GASウェブアプリは「全員」に公開するため、合言葉で完全に非公開になるわけではありません。
- 合言葉はブラウザの保存領域に置くため、共有PCでは使わず、ブラウザの拡張機能や端末の管理にもご注意ください。
- スマホとPCは別ブラウザのため、各端末でGAS URLと合言葉を一度保存する必要があります。
- Googleスプレッドシートの内容をブラウザへ自動的に読み込む双方向同期ではありません。
- 初回連携後、誤った合言葉でもローカル保存は続きますが、シートへの自動反映は停止します。「接続テスト」で確認してください。

詳しい設定は `START-HERE.md` と `GAS-SETUP/SETUP-README.txt` を参照してください。
