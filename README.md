# お気に入りボックス v2.1.0

## 最新版
- パソコンとスマホで同じGoogleスプレッドシートを使う自動同期機能
- 起動時、画面復帰時、約60秒ごとに自動で反映。手動同期ボタンあり。
- 追加・編集・削除のクラウド反映。クラウド側で削除した既知のIDの削除も端末に反映。
- リンク共有によるスマホへのGAS初回接続設定の自動取り込み。
- 端末に未送信の変更がある間はクラウドからの古い内容で上書きしないよう保護。
- 既存データとGASの保存先には変更なし。GAS v2.0.0を継続利用。
